## Achados

### [MÉDIA] `%ProgramData%\ITC\Bench` herda o ACL padrão do ProgramData
- **Arquivo:** `src/itc_bench/nucleo/caminhos.py` · linhas 27–30 (`inicializar()`)
- **Trecho:** `pasta.mkdir(parents=True, exist_ok=True)`, sem ACL explícito.
- **Verificado em máquina real** (`icacls C:\ProgramData\ITC\Bench\logs`): `BUILTIN\Usuários:(CI)(WD,AD,WEA,WA)`
  e `PROPRIETÁRIO CRIADOR:(OI)(CI)(IO)(F)`. Qualquer usuário comum cria arquivos e pastas ali e
  fica dono deles.
- **Por que é explorável:** um usuário do notebook (aluno) pode criar `bench.log` ou um arquivo de
  rotação antes da primeira execução elevada e depois editar o log, que registra o que o técnico
  fez. No Módulo 04 o cache DPAPI vai para a mesma árvore; lá o risco cresce (troca de arquivo).
- **Condição:** acesso local com conta comum. Hoje o log não tem dado sensível nem é lido pelo app.
- **Correção planejada:** `inicializar()` em execução elevada aplica ACL explícito (sem herança;
  SYSTEM e Administradores `S-1-5-32-544` controle total; Usuários leitura) usando a API do Windows,
  sem `icacls` por shell. Entra como item do Módulo 02 (executor) ou, no máximo, antes do cache do
  Módulo 04. Checkbox adicionado em `docs/IMPLEMENTATION-PLAN.md`. Não bloqueia o fechamento (média).

### [INFORMATIVA] Rodapé da barra lateral em rich text automático
- **Arquivo:** `src/itc_bench/ui/janela.py` · rodapé (`QLabel(f"{hostname} · {usuário}<br>Bench ...")`)
- **Por que importa:** o `<br>` faz o Qt interpretar o texto como HTML. Hoje só entram o hostname
  (não aceita `<`) e o nome do usuário local, dados da própria máquina. Quando qualquer dado da API
  entrar num `QLabel`, usar `Qt.TextFormat.PlainText`.

### [INFORMATIVA] Fontes e lock baixados da internet
- **Arquivos:** `src/itc_bench/recursos/fontes/README.md`, `uv.lock`
- **Por que importa:** cadeia de suprimento. Fontes com URL, commit e SHA-256 registrados; `uv.lock`
  com hash de cada pacote, só de `pypi.org` e `files.pythonhosted.org`. `.gitattributes` impede
  conversão de fim de linha nos recursos, para o SHA-256 continuar batendo.

## Achados

### Informativo 1 — Link simbólico de registro plantado no hive do usuário
Um usuário comum não grava nas raízes de política, mas grava em `Software` do próprio hive. Se
`Software\Policies` não existir, ele pode criar ali uma chave que seja um link simbólico de
registro. O Bench, como admin, escreveria através dela.
- O Windows bloqueia link simbólico de hive não confiável para hive de máquina desde a correção
  de 2016 (MS16-124), então o destino ficaria no próprio hive do usuário.
- `Software\Policies` existe em todo perfil criado pelo Windows.

Fica como está. Cenário V5 no roteiro.

### Informativo 2 — Contas futuras incluem administradores criados depois
A política no perfil padrão vale para toda conta nova, inclusive admin. A confirmação avisa;
desfazer em Contas futuras não muda contas já criadas.

### Informativo 3 — Timeout no meio da escrita
Uma escrita que passe de 60 s é encerrada e pode deixar parte das políticas de um alvo
aplicadas. A situação mostra "diferente" e reaplicar é idempotente. O hive temporário é
descarregado mesmo assim.

### Informativo 4 — Pasta Inicializar por `%PROGRAMDATA%`
A pasta vem do ambiente do processo elevado (mesmo padrão de `nucleo/caminhos.py`). Um ambiente
trocado só mudaria onde o Bench procura dois nomes fixos para apagar.

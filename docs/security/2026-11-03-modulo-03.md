## Achados

### [INFORMATIVA] Qualquer carreta lê o histórico de qualquer hostname
- **Arquivo:** `api/app/routes/relatorio.py:133-146` (`historico_rota`) e `:40-46` (`historico`)
- **Trecho:** `WHERE d.hostname = ?`, sem filtro por `carreta`.
- **Por que importa:** é IDOR por desenho: um token de carreta vê os diagnósticos de máquinas de
  outras carretas. Documentado em `docs/api/API.md:128` (máquinas trocam de carreta). Exige token
  válido e passa pelo Cloudflare Access. Revisitar no Módulo 04, quando o login do técnico existir.

### [INFORMATIVA] Diretório de deploy interpolado na linha de comando remota
- **Arquivo:** `.github/workflows/api-deploy.yml` · passo `pull, build and health check on glpi-srv`
- **Trecho:** `"bash -s -- '$GITHUB_SHA' '$DEPLOY_APP_PORT' '$DEPLOY_DIR'"`
- **Por que importa:** um valor com aspa simples quebraria o comando. Os três valores são o SHA do
  próprio run e secrets do environment `producao`, que só administradores do repo gravam; mesmo
  padrão do workflow de origem. Sem entrada de PR ou de usuário.

### [INFORMATIVA] Hosts reais no histórico do tecnico-assistente continuam públicos lá
- **Onde:** repo `ITC-Brasil/tecnico-assistente` (docs, workflows).
- **Por que importa:** não entram aqui (a importação é só de `api/`, com `--replace-text`), mas o
  repo de origem segue com eles até ser arquivado. Fora do escopo deste repo; o responsável decide
  a visibilidade do arquivado.

### [INFORMATIVA] Commits do PR #8 com hosts reais seguem acessíveis pelo SHA
- **Onde:** PR #8 (fechado sem merge), commit de fechamento da primeira versão da branch.
- **Por que importa:** dois docs listavam os valores procurados na varredura e as regras de
  substituição. A branch foi reescrita sem eles (`chore/modulo-03-monorepo-v2`) e a antiga
  apagada, mas o GitHub continua servindo esses commits pelo SHA, via PR #8, até o garbage
  collection. Mesmo tipo de dado do ADR-009 (nomes de host e usuário, sem credencial): risco
  aceito por esse ADR. Regra nova no `AGENTS.md`: documento com padrões de varredura ou regras de
  substituição usa placeholders.
